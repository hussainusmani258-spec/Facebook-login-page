# Facebook Login Page Clone

A clean, responsive, and pixel-perfect Facebook Login Page clone inspired by the official login UI. Built using semantic HTML5 and clean CSS3 layouting.

📌 Features

* Clean UI: Accurate replica of the official Facebook desktop login card and branding section.
* Two-Column Layout: Left side features the Facebook logo and tagline, right side contains the interactive login card.
* Form Components: Input fields for Email/Phone and Password, Login button, Forgot Password link, and "Create new account" button.
* Flexbox Alignment: Centered container layout using standard CSS flexbox.
* Human-Coded Style: Straightforward, readable HTML/CSS structure without unnecessary code complexity.

🛠️ Tech Stack

* HTML5
* CSS3
